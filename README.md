# Shop Quoter

Mobile-first offline PWA for a small laser and 3D-print shop: quotes, jobs, a weekly to-do list, a product price list, and a settings screen that holds every business number. Plain HTML/CSS/JS, no build step. Data stays in the phone's localStorage, with JSON export and import for backups.

Open the hosted page in Chrome on Android, then use ⋮ → Add to Home screen.

If you edit any app file, change `CACHE` in `sw.js` (for example `shop-v2`) so phones pick up the update.
